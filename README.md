# FOR ALL BARBER Pro

Create a premium mobile-first website for a luxury house-call barber service called "FOR ALL BARBER".



IMPORTANT:

This is NOT a traditional barbershop website.

This business operates like Uber. Customers book a barber who travels to their location.

The design should feel like Uber Black, Blacklane, Apple, and modern luxury brands.



STYLE:

- Ultra premium

- Dark luxury aesthetic

- Black, charcoal, silver, and white color palette

- Minimal gold accents only if necessary

- High-end typography

- Spacious layout

- Smooth animations

- Mobile-first responsive design

- Clean and modern

- No generic barber website templates

- No vintage barber aesthetic

- No clutter
